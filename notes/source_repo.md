# 원본 SUREFlow Repository

실습에서 사용한 원본 SUREFlow GitHub repository는 다음이다.

```text
https://github.com/tanvirnwu/SUREFlow_IROS_2026
```

Clone 명령어:

```bash
cd ~/projects
git clone --recurse-submodules https://github.com/tanvirnwu/SUREFlow_IROS_2026.git SUREFlow
cd SUREFlow
```

기존 문서에서 `https://github.com/tanvirnwu/SUREFlow.git`처럼 작성된 부분은 이 repository 기준으로 수정하면 된다.

## 실습 repository와의 관계

```text
원본 코드 repository:
https://github.com/tanvirnwu/SUREFlow_IROS_2026

실습 정리 repository:
https://github.com/kibum0613/SUREFlow_tutorial
```

`SUREFlow_tutorial` 저장소는 원본 코드를 그대로 복제한 저장소가 아니라, WSL2 Ubuntu 환경에서 SUREFlow를 실행하면서 발생한 설치 문제, 코드 수정, 학습 설정, 평가 결과를 정리한 튜토리얼 저장소이다.
